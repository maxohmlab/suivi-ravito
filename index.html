Comment utiliser cet outil

  1. Planifie une séance dans l'onglet Séance (type "Prévision") : semaine, date, durée, cible CHO/h, produits envisagés. Enregistre — elle apparaît dans "Planifiées".
  2. Le jour J, rouvre-la via "Modifier" dans l'onglet Planifiées, ajuste les quantités réellement prises, passe le type sur "Réalisé", enregistre — elle bascule dans "Historique".
  3. Le calculateur rapide te dit combien d'un produit il faut pour couvrir ta cible sur la durée prévue, et à quel rythme le prendre.
  4. Édite librement les produits de la bibliothèque (✎) si tu changes de marque ou si une valeur d'étiquette diffère — Les produits de référence sont partagés et en lecture seule ; tes produits personnels restent modifiables.
  5. Les données sont sauvegardées automatiquement dans ton compte Supabase. Tu peux exporter un fichier JSON comme sauvegarde personnelle.

Un exemple réel de plan de progression CHO/h utilisé pour un marathon (ici Bruges, oct. 2026), donné à titre d'inspiration — libre à toi d'adapter les semaines, dates et cibles à ta propre course dans l'onglet Séance.

Principes qui sous-tendent cette progression :

  • Le débit CHO/h augmente semaine après semaine, mais l'objectif final est un ratio d'exécution réel/plan ≥95% le jour J — pas seulement un chiffre ambitieux sur le papier.
  • Chaque sortie longue inclut un ou plusieurs blocs à allure marathon, avec une prise de gel juste avant, pour tester la digestion en conditions d'effort réelles (pas seulement à allure d'endurance tranquille).
  • On évite de tester deux variables nouvelles à la fois (ex : nouveau format de gel + caféine simultanément), pour isoler ce qui est bien ou mal toléré.

Points de vigilance produits

  • Les remarques spécifiques à chaque produit (sodium non confirmé, dosage conseillé, risque de confusion entre gammes...) sont affichées directement sous sa fiche dans l'onglet Séance — clique sur ✎ pour les consulter ou les modifier.
  • Les caractéristiques des produits sont centralisées dans la bibliothèque : si une valeur change, les calculs des séances qui utilisent ce produit utilisent la nouvelle valeur.
